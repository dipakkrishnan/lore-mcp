# capture

Prefix: `CAP`

Covers: getting non-session content into Lore — the attended `lore-capture`
skill (agent-runtime intake of files, voice, and pasted text) and, as they
land, the unattended rails from issue #8 (inbox dropbox, `lore capture` CLI)
plus the shared extraction pipeline (`lore/extract.py`).

Backlog items about ingesting content that never touched an agent session go
here. Session-exhaust synthesis stays with automation/onboarding.
