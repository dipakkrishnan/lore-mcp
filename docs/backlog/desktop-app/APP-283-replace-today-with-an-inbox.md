## Problem

Today is a date eyebrow, a greeting and a capture hero, then up to eight kinds of card. Principles §6 ask for an
Inbox: one row type, one verb each, and "You're all caught up" when empty.

## Proposed approach

Audit step 5. Waits on the owner's answer on naming the sidebar places (Inbox, Inventory, Bids, Connectors).
Capture moves to ⌘K and New (APP-281 already lists Memory under New).

## Acceptance criteria

- [ ] The home view is one list of rows, each with one verb; empty says "You're all caught up".
