## Problem

⌘K finds memories but runs no commands. Settings rows carry paragraphs and mix a pill, a link and a button. Help
is a page of Q&A cards in the app.

## Proposed approach

Audit step 6: ⌘K commands (Go to…, Connect…, New collection, Set price) with shortcuts; Settings rows as label +
one line + one control; Help opens the website's FAQ from the workspace menu.

## Acceptance criteria

- [ ] Every New and workspace-menu item is reachable from ⌘K.
- [ ] Each Settings row has one control.
